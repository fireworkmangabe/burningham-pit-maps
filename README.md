# Burningham Trucking — Pit Maps

View-only interactive maps of the Red Dome, Sand Pit, and Travertine sites.

This site is for viewing only. Anyone with the link can zoom, pan, and browse labels. Pins cannot be added, moved, or edited here.

Suggested pins (plants, conveyors, entrances, offices, scales, shops, and parking areas) are included. Some names are approximate and should be verified on site.
